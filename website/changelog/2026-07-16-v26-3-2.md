Braid's macOS auto-updater now runs on Electron's own update machinery instead of a third-party library. Updates are more reliable, and Braid always asks before installing - no surprise background swaps.

{/* truncate */}

## Changed

- **Native auto-updates** - Migrated the macOS updater from `electron-updater` to Electron's built-in Squirrel.Mac, backed by the official `update.electronjs.org` service. This means fewer moving parts and more dependable update delivery.
- **You stay in control** - Release discovery is now decoupled from downloading. Braid tells you an update is available and waits for you to accept it before pulling the new build, so updates never install behind your back.
