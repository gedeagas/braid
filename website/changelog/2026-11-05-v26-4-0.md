Braid now has its own browser. Open web pages as tabs right next to your chats and terminals, keep a separate tab set for every worktree, and let your agents drive the same pages you're looking at: reading content, clicking, typing, and taking screenshots. This release also makes agent status show up the moment Braid starts, and gives the whole interface a legibility pass.

{/* truncate */}

## Added

- **A built-in browser** - Open browser tabs from the "+" menu in the tab bar, alongside your chat sessions and terminals. It has an omnibox with your choice of search engine, back and forward navigation, find-in-page, downloads, and pop-up handling. Each worktree keeps its own tabs, so switching worktrees brings back the pages you had open there.
- **Side-by-side split** - Split the center pane to keep a browser next to a chat or terminal, ideal for watching a dev server while an agent works on it.
- **Browser profiles** - Each profile has its own cookies, storage, and cache. Pick one from the browser toolbar to stay signed in to different accounts, or clear a profile's data from Settings.
- **Import your cookies** - Bring sign-ins over from Chrome, Edge, or a `cookies.txt` / JSON file so you don't have to log in to everything again.
- **Agents can use the browser** - Chat sessions have browser tools built in, so Claude can read a page, click, type, and take screenshots. Turn on **Let terminal agents use the browser** to put a `braid-browser` command on every Braid terminal's PATH and install a small skill for Claude Code, Codex, Cursor, Gemini, Copilot, Droid, Grok, and more, so terminal agents know it exists. Agent commands use the tab's profile, so they see the same signed-in pages you do.
- **Optional MCP registration** - Add a `braid-browser` MCP server to the global configs of Claude Code, Codex, Gemini, Cursor, and Copilot. It's off by default because it edits those agents' config files, and turning it off removes the entries again.
- **Choose where links open** - Send links from terminals, chat, markdown, and the editor to Braid's browser or your system browser. Hold the modifier key while clicking to send a single link the other way.
- **Chat font size** - Adjust chat text from 12 to 20px in Settings > Appearance.

## Improved

- **Agent status from the first second** - Live agent terminals in every worktree reconnect on startup, so sidebar agent counts, status badges, and Mission Control are correct right away, without clicking into each worktree first.
- **Easier to read and click** - Small icons now render at a 12px minimum, the smallest text sizes are slightly larger, and compact icon buttons have a bigger invisible hit area.
- **Readable on every theme** - Secondary and muted text is automatically adjusted to meet WCAG AA contrast, including on custom and imported themes.
- **Visible keyboard focus** - Tabbing through the app now shows a clear focus ring on every interactive element.

## Other

- Updates are now delivered through Braid's own update server instead of Electron's shared service, giving us more control over how releases reach you.
